# MEMO Life Studio — System Master

## Core Loop

Home / garden decoration → lifestyle state improves → outfit / trip / creative activities unlock → earn currency / memories / inspiration → collect fashion, furniture and cat items → expand spaces → share UGC / visit friends.

## 1. Home & Garden

BuildZone is the reusable base unit.

Types:
- Bedroom
- Living Room
- Wardrobe
- Studio
- Balcony
- Courtyard
- Garden
- Poolside

Each placeable object carries:
- category
- footprint
- rotation
- zone compatibility
- style tags
- mood effects
- feng shui element
- cat interaction anchors

## 2. Wardrobe

Slots:
- Hair
- Top
- Bottom
- Dress
- Outerwear
- Shoes
- Bag
- Jewelry
- Accessories
- Travel item
- Cat accessory

Attributes:
- Chic
- Comfort
- Mood
- Confidence
- Travel Ready
- Creative
- Romantic

Use scene requirements rather than one fixed correct outfit.

## 3. Travel

Flow:
Trip invitation → destination → packing checklist → outfit preparation → departure → postcard / on-site scene → return → memories + rewards.

Possible live states:
- heroine away; player stays home and cares for cat
- heroine invites player on-site
- friend sends postcard / photo
- travel-inspired furniture / clothes unlock
