# MEMO Brand Master

## 1. Brand Definition

**MEMO = Memory of the Universe**

Primary line: **Wear Your Good Mood.**

Category definition: **Inside–Outside Wardrobe / Playful Premium Lifestyle**

MEMO is not a conventional lingerie brand and not a pajama label. The product system is designed around transitions:
- home → street
- innerwear → outerwear
- airport → hotel
- business → bar
- pool → resort
- city → weekend
- day → night

## 2. Consumer

Core mindset: **young at heart, active, style-conscious, quality-conscious, playful but not childish**.

The collection should work across a wide adult age range without creating an “older” sub-line. Instead use:
- multiple coverage options
- adjustable fit
- regular / full cup where necessary
- petite / regular lengths
- soft support
- clean tailoring
- movement-friendly construction

## 3. Visual Tone

MEMO should feel:
- premium
- clean
- feminine
- cool rather than sugary
- slightly flirty
- playful
- modern
- self-expressive
- travel-ready
- editorial

Avoid:
- generic marketplace / white-label appearance
- all-over lace as the default
- over-decoration on every seam
- cheap shiny gold
- childish cartoon styling
- one-color monochrome looks as the only styling logic
- “sleepwear only” silhouettes
- stiffness or restrictive tailoring

## 4. Signature Design DNA

### A. Silhouette
- asymmetric neckline
- one-shoulder constructions
- bias drape
- side knot
- cropped refined jacket
- clean mini / midi
- straight trouser, tailored short, modern denim
- non-restrictive lounge pant
- inner top designed to be visible

### B. Small Details
Use **one to three** per garment:
- scalloped edge
- tiny bow
- contrast piping
- detachable cat charm
- cat button
- micro embroidery
- 3D flower
- feather cuff / hem
- unexpected color lining
- shaped pocket
- custom zipper pull
- asymmetric strap

### C. Brand Codes
- hand-drawn line cat
- Variable Cat / same cat, different mood
- cat hardware
- mood-based color
- handwritten micro-copy
- “good mood” objects
- signature travel accessories

## 5. Material Strategy

### MEMO Air
TENCEL™ Modal / Supima cotton / rib / pointelle.

### MEMO Glow
Naia™ acetate / premium viscose satin / silk-touch fabric.

### MEMO Silk
19–22 momme washable silk for hero products.

### MEMO Tailoring
light tweed / textured cotton / crease-resistant suiting / soft denim.

### MEMO Swim
supportive fast-dry technical fabric.

## 6. Palette

Hero family:
- Archive Pink
- Rose Pink
- Lilac
- Pool Blue
- Mint
- Butter Yellow
- Cream
- Soft Coral
- Champagne

The brand must not rely on pink alone. Color stories should mix across looks.

## 8. Bag System

- **Work Tote** — laptop, documents, bottle, small pouch
- **Crossbody** — hands-free business / city
- **Evening Clutch** — phone, card, lipstick, keys
- **Bucket Bag** — vertical tumbler / drink compartment + daily essentials
- **Travel Weekender** — soft structured overnight bag
- **Packing Pouches** — lingerie, beauty, cables, sleep, swim

## 9. Scene System

MEMO should always be shown in a real life sequence:
- getting ready
- airport
- hotel
- meeting
- city walk
- interview / coffee
- dinner
- hotel bar
- party / yacht
- sleep / reset
- workout
- resort

## 10. Brand Rule

**Before the logo is visible, the garment should already feel like MEMO.**
