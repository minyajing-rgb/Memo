Read definition/full approved PRD/mockups/flows/architecture. Freeze exact source commit/build/URL/environment/time/browser/device/locale/width. ALL concrete pages/dynamic instances/nested branches/tabs/modals/controls/states are denominator; compare router and visible links, include newly found pages. PASS/FAIL/BLOCKED/NA_WITH_REASON, untested BLOCKED. Report numerator/denominator.
Create PAGE_REVIEW_CARD per page: requirement/flow/mockup IDs; expected/actual; desktop/mobile actual-reference pairs; content/source/translation/imagery; every control's destination/side effect; every state; keyboard/names/focus/touch/zoom/motion; console/network/private access/metadata; evidence commit/defect IDs. Open actual pixels beside approved mockups: hierarchy/spacing/type/contrast/images/cropping/readability, overlap/clipping/long text/sticky bars. Capturing screenshots, DOM tests, HTTP200 and builder claims do not certify visuals. Previews are not restored high-resolution originals; emulation is not physical-device QA.
Exercise all positive/alternative/failure paths: empty/invalid/long input, loading/success/no-results/errors/timeouts/offline/retry, permissions/storage denied, guest/auth, cancel/back/refresh/deeplink/repeated actions. Verify real state/network and applicable auth/RLS/data/model/forms/payments safely; no unauthorized charges/messages/private writes or weakened security. Check visitor value, architecture/privacy/locales/SEO/measured performance.
DEFECTS.json records severity/page/state/requirement, reproduction, expected/actual, evidence, owner, fixing commit, same-case RETEST and affected regressions. Fix authorized issues and retest; untested fixes remain open. P0 security/data-loss; P1 broken/missing required flow or essential visual evidence/misleading success; P2 quality. Gate B implemented+built. Gate C INTERNALLY_ACCEPTED only full coverage+actual pixel inspection+zero open P0/P1+explicit P2 exceptions. Otherwise NOT_READY, no quiet scope waiver.
Gate D LIVE_VERIFIED only after authorized publication: actual domains/redirects/body/title/asset hashes vs tested build, all live routes/locales/critical flows, console/network, canonical/lang/OG/SEO and auth/rollback. SPA200 can serve wrong page. Missing candidate NOT_DEPLOYED; preview and rebuilt production need separate tests. Never publish or redo backups solely to pass.
Reuse evidence only when diff proves page AND shared data/styles/translations unchanged; unknown mappings fail closed. Label method/version. Hand over only independently checked candidate with actual previews, coverage, defects/build, not repeated requests for owner review. Full templates at pinned canonical .agents/skills. COPIED, ACTIVATION_TESTED, AUTOMATION_RUNNING are distinct; files alone are not global runtime activation.
