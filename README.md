# MEMO — Memory of the Universe

**Wear Your Good Mood.**

MEMO is a playful-premium lifestyle wardrobe built around one idea: clothing should move naturally between **home, work, travel, city, resort and after-hours**.

The brand combines:
- refined comfort
- inner-to-outer dressing
- travel-ready layering
- playful color
- signature cat details
- precise, feminine tailoring
- small hardware, embroidery, bows, asymmetric cuts and contrast trims

## Brand Architecture

- **MEMO Intimates** — innerwear that can be worn as tops
- **MEMO Lounge** — silk / modal homewear that can leave the hotel room
- **MEMO Ready-to-Wear** — business-to-bar, city and resort separates
- **MEMO Travel** — capsule wardrobe, bags and packing system
- **MEMO Swim** — pool / beach / resort
- **MEMO Men** — soft tailoring + resort lifestyle
- **MEMO Objects** — bags, charms, pouches, scarves, caps, tumblers
- **MEMO Fortune** — seasonal “peach blossom / good luck” campaign graphics and collectible cards

## Visual Lock

**Palette:** Archive Pink, Rose, Lilac, Pool Blue, Mint, Butter Yellow, Cream, Soft Coral, Champagne.

**Signature design cues:** cat charm hardware, cat embroidery, micro-print, contrast piping, refined scalloped edge, tiny bows, asymmetric draping, selective feather trims, premium satin / silk / modal / pointelle / tweed.

**Rule:** never look like a white-label pajama or generic marketplace product. The silhouette, material and detail must read as MEMO before the logo is visible.
